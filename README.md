## 🇧🇷 Português

### Sobre o projeto

Portfólio pessoal desenvolvido para apresentar minha trajetória, stack técnica e projetos como desenvolvedora full stack e especialista em IA. Construído inteiramente com **HTML, CSS e JavaScript puros** — sem frameworks, sem build step — de propósito, para que o próprio código-fonte funcione como material de estudo e demonstração de fundamentos.

### ✨ Funcionalidades

- 🌗 **Modo claro/escuro** com preferência salva no navegador
- 🌍 **4 idiomas** (Português, Inglês, Espanhol, Japonês) via sistema de tradução customizado
- 🎬 **Animação vetorial** (Lottie) no topo, leve e escalável
- 🔍 **Stack técnica filtrável** por categoria (Frontend / Backend & IA / Boas práticas)
- 📱 **Totalmente responsivo**, com menu mobile próprio
- 📄 **Currículo em PDF** para download (PT/EN)
- ♿ **Acessibilidade**: atributos ARIA, `prefers-reduced-motion`, contraste testado (WCAG AA/AAA)
- ⚡ Sem dependências externas de build — abre em qualquer navegador

### 🛠️ Stack utilizada

| Camada | Tecnologias |
|---|---|
| **Estrutura** | HTML5 semântico |
| **Estilo** | CSS3 (Custom Properties, Flexbox, Grid, Media Queries, `@keyframes`) |
| **Interatividade** | JavaScript (Vanilla, DOM API, `IntersectionObserver`, `localStorage`) |
| **Animação** | [Lottie-web](https://github.com/airbnb/lottie-web) |
| **Tipografia** | Space Grotesk · Inter · JetBrains Mono (Google Fonts) |
| **Hospedagem** | GitHub Pages |

### 📁 Estrutura do projeto

```
├── index.html          → estrutura, conteúdo e lógica (i18n, tema, filtros)
├── style.css            → todo o estilo visual
├── lottie.min.js         → biblioteca de animação
├── hero-dev.json         → dados da animação do topo
├── cv-pt.pdf              → currículo em português
├── cv-en.pdf              → currículo em inglês
└── favicon.svg            → ícone do site
```

### 🚀 Rodando localmente

Não precisa de instalação, servidor ou build:

```bash
git clone https://github.com/samira-silva/samira-dev.git
cd samira-dev
# abra o index.html diretamente no navegador
```

### 🎨 Personalizações principais

- **Tema**: cores centralizadas em variáveis CSS (`:root` e `[data-theme="dark"]`) no topo do `style.css`
- **Traduções**: dicionário `translations` dentro do `index.html`, com uma chave por texto e um bloco por idioma
- **Conteúdo**: seções marcadas com `data-i18n="chave"` — trocar o texto no dicionário atualiza automaticamente todos os idiomas

## 🇺🇸 English

### About the project

Personal portfolio built to showcase my background, technical stack and projects as a full stack developer and AI specialist. Built entirely with **vanilla HTML, CSS and JavaScript** — no frameworks, no build step — by design, so the source code itself works as study material and a demonstration of fundamentals.

### ✨ Features

- 🌗 **Light/dark mode** with preference saved in the browser
- 🌍 **4 languages** (Portuguese, English, Spanish, Japanese) via a custom translation system
- 🎬 **Vector animation** (Lottie) in the hero, lightweight and scalable
- 🔍 **Filterable tech stack** by category (Frontend / Backend & AI / Best practices)
- 📱 **Fully responsive**, with a custom mobile menu
- 📄 **Downloadable résumé** in PDF (PT/EN)
- ♿ **Accessibility**: ARIA attributes, `prefers-reduced-motion`, tested contrast (WCAG AA/AAA)
- ⚡ No external build dependencies — opens in any browser

### 🛠️ Tech stack

| Layer | Technologies |
|---|---|
| **Structure** | Semantic HTML5 |
| **Styling** | CSS3 (Custom Properties, Flexbox, Grid, Media Queries, `@keyframes`) |
| **Interactivity** | Vanilla JavaScript, DOM API, `IntersectionObserver`, `localStorage` |
| **Animation** | [Lottie-web](https://github.com/airbnb/lottie-web) |
| **Typography** | Space Grotesk · Inter · JetBrains Mono (Google Fonts) |
| **Hosting** | GitHub Pages |

### 📁 Project structure

```
├── index.html          → structure, content and logic (i18n, theme, filters)
├── style.css             → all visual styling
├── lottie.min.js          → animation library
├── hero-dev.json          → hero animation data
├── cv-pt.pdf               → résumé in Portuguese
├── cv-en.pdf               → résumé in English
└── favicon.svg             → site icon
```

### 🚀 Running locally

No installation, server, or build step required:

```bash
git clone https://github.com/samira-silva/samira-dev.git
cd samira-dev
# open index.html directly in your browser
```

### 🎨 Key customizations

- **Theme**: colors centralized as CSS variables (`:root` and `[data-theme="dark"]`) at the top of `style.css`
- **Translations**: `translations` dictionary inside `index.html`, one key per text string and one block per language
- **Content**: sections marked with `data-i18n="key"` — editing the dictionary automatically updates every language
